Install

Cursor Pick one path — Option A is fastest; Option C is best for analyzing AIAutomation / TaxMesh every day.

A) Cursor Settings → Plugins (easiest)

  1. Open Cursor Settings → Plugins.
  2. Paste https://github.com/Egonex-AI/Understand-Anything and add the plugin.
  3. Reload Cursor.
  4. Open your target project → Agent chat → /understand.

B) Clone & open the plugin repo (auto-discovery)

git clone https://github.com/Egonex-AI/Understand-Anything.git
# File → Open Folder on that clone
# Cursor reads .cursor-plugin/plugin.json
Good for exploring the plugin itself. To analyze other repos, use A or C.

C) Personal skills for all projects (recommended with AIAutomation)

Links skills into %USERPROFILE%\.cursor\skills\:

git clone https://github.com/Egonex-AI/Understand-Anything.git C:\src\Understand-Anything
cd C:\src\Understand-Anything
pnpm install
pnpm --filter @understand-anything/core build
pnpm --filter @understand-anything/skill build

cd C:\Project\AIAutomation
$env:UA_DIR = "C:\src\Understand-Anything"
.\scripts\install-understand-anything-cursor.ps1

Uninstall junctions:

.\scripts\install-understand-anything-cursor.ps1 -Uninstall

VS Code / Visual Studio Personal path: %USERPROFILE%\.copilot\skills\

  1. Clone & build Understand-Anything: 
    git clone https://github.com/Egonex-AI/Understand-Anything.git
cd Understand-Anything
pnpm install
pnpm --filter @understand-anything/core build
pnpm --filter @understand-anything/skill build
  2. Install for Copilot (platform id is vscode for both VS Code and Visual Studio): 
    .\install.ps1 vscode
    Or: 
    iwr -useb https://raw.githubusercontent.com/Egonex-AI/Understand-Anything/main/install.ps1 | iex
# choose: vscode
  3. Restart the IDE → Copilot Agent mode → open target project → /understand.
Visual Studio has no separate installer platform — always use vscode.

How to use (Cursor or Copilot)

  1. Open the TARGET workspace (TaxMesh / app under test / AIAutomation).
  2. Open Agent chat (Cursor Agent, or Copilot Agent).
  3. First analysis: 
    /understand
    If slash skills are missing: 
    Use the understand skill to analyze this project.
  4. After .ua/ exists: 
    /understand-dashboard
/understand-chat How does validation INFO naming work?
/understand-explain path\to\File.ts
/understand-diff
/understand-onboard

Troubleshooting

  • Cursor doesn’t see skills — Use Settings → Plugins with the GitHub URL, or run install-understand-anything-cursor.ps1, then reload.
  • Slash commands missing — Ask in plain language: “Use the understand skill…”
  • Wrong project analyzed — Open the target app as the workspace root first.
  • Core import errors — Rebuild with pnpm filters in the Understand-Anything clone.
  • VS / VS Code — Always install.ps1 vscode (no separate Visual Studio platform).
